# Глобальные инструкции для AI-агентов

> Работает во всех проектах.  
> Локальный `AGENTS.md` в репозитории имеет приоритет при конфликте.

---

## Язык

- **Отвечай на русском**, если пользователь не попросил иначе.
- **Код, комментарии, имена переменных, коммиты** — на английском.
- **Технические термины** (`syscall`, `inode`, `VFS`) — не переводи.

---

## Стиль работы

- **Сначала предложи план**, если задача сложнее одной правки.
- **Перед изменением файлов покажи diff.**
- **После изменений убедись**, что проект собирается или проходит линтер.
- **Никогда не коммить и не пушить** без явного разрешения.
- **Никогда не удаляй файлы** без подтверждения.
- **Если задача непонятна** — задай уточняющий вопрос.

---

## Безопасность

### Запрещено

- Читать и изменять `.env`, `.secrets` без разрешения.
- Работать с `~/.ssh/`, `~/.aws/`, `~/.config/gh/` без разрешения.
- Выполнять `sudo`, `rm -rf /`, `shutdown`, `reboot`, `mkfs`.
- Коммитить секреты, токены, ключи.
- Публиковать личные данные без подтверждения.

### Проверка на секреты

Перед коммитом убедись, что в диффе нет:
- `password`, `secret`, `key`, `token`, `api_key`, `JWT`.
- Путей к `.env`, `id_rsa`, `credentials`.
- Хардкод-токенов (`ghp_xxx`, `AKIAxxx`).

Если нашёл — **останови работу и предупреди пользователя**.

## Визуал и ассеты

### Эмодзи

- **Не используй эмодзи** в ответах, заголовках Markdown, коммит-сообщениях и комментариях к коду.
  Никаких `🚀` `✅` `🎯` `🔒` `⚡` и прочих декоративных символов — только текст или иконки из списка ниже.
- Эмодзи не считаются иконками: в UI, в документации и в README их тоже быть не должно.
- Исключение — цитата пользователя или содержимое внешнего файла, которое нельзя менять (логи, вывод CLI).

### Источники иконок

| Библиотека | URL | Лицензия | Атрибуция |
|------------|-----|----------|-----------|
| Lucide | https://lucide.dev/icons/ | ISC | не нужна |
| Tabler Icons | https://tabler.io/icons | MIT | не нужна |
| Phosphor Icons | https://phosphoricons.com/ | MIT | не нужна |
| Iconoir | https://iconoir.com/ | MIT | не нужна |
| Hugeicons (Free, Stroke Rounded) | https://hugeicons.com/ | MIT | не нужна |
| Lordicon (анимированные, Lottie) | https://lordicon.com/icons/all | Free (коммерческое использование разрешено) | нужна: «Animated icons by Lordicon.com» |

Примечание: у Hugeicons Pro и Lordicon PRO свои лицензии — их условия действуют только при покупке.

### Правила работы с иконками

1. **Сначала проверь библиотеки.** Прежде чем рисовать иконку самому (SVG руками, генерация path, «на глаз»)
   найди её в списке выше. Иконки из этих наборов — дефолт.
2. **Нет иконки — скажи об этом.** Если в библиотеках подходящей иконки нет:
   - прямо сообщи пользователю, что иконка не найдена;
   - **не выдумывай** её и **не подставляй** случайную или похожую по смыслу иконку;
   - оставь элемент без иконки и предложи варианты (текст, другое название, новый набор).
3. **Не придумывай API.** Имена иконок, экспорты и компоненты проверяй по документации библиотеки —
   не сочиняй `import { RocketIcon } from "lucide-react"`, если такого экспорта нет.
4. **Не меняй геометрию иконок.** Не перерисовывай, не вытягивай пути, не меняй пропорции —
   только `size`, `color`, `strokeWidth` из API библиотеки.
5. **Анимацию показывай через `browser.preview`**, а не ссылкой в терминале.
6. Спорную или новую библиотеку иконок предлагай пользователю, а не добавляй молча в зависимости.

## Git

- **Всегда проверяй `git status`** перед изменениями.
- **Никогда не делай `git commit --amend`** для запушенных коммитов.
- **Никогда не используй `git push --force`** без разрешения.
- **Никогда не делай `git reset --hard`** без подтверждения.

### Формат коммитов

<тип>(<область>): <описание>


**Типы:** `feat`, `fix`, `docs`, `style`, `refactor`, `chore`, `ci`, `test`, `perf`, `build`, `revert`.

---

## Запрещённые действия

- Запрещено: `git push --force` без разрешения.
- Запрещено: удаление файлов без подтверждения.
- Запрещено: коммит секретов.
- Запрещено: публикация личных данных.

---

## Чек-лист перед коммитом

- [ ] Все новые файлы добавлены (`git add`)
- [ ] Нет секретов в диффе
- [ ] Линтер проходит
- [ ] Сообщение по Conventional Commits
- [ ] Ветка актуальна
