# Горячие клавиши

## Окно и система

| Клавиши | Действие |
|---|---|
| `Print` | скриншот всего экрана |
| `Shift+Super+S` | выделить область и сделать скриншот |
| `Super` | обзор всех окон |
| `Super+L` | заблокировать экран |
| `Super+A` | все приложения |
| `Super+Tab` | переключение окон |
| `Alt+F4` | закрыть окно |

## Быстрые действия (перенесены с ноутбука Михаила)

Работают и на цифровом блоке, и на обычных цифрах.

| Действие | С цифровым блоком | На любой клавиатуре |
|---|---|---|
| GitHub | `Ctrl+NumPad-2` | `Ctrl+Alt+1` |
| YouTube подписки | `Ctrl+NumPad-1` | `Ctrl+Alt+2` |
| LeetCode | `Ctrl+NumPad-3` | `Ctrl+Alt+3` |
| Шпаргалка (этот файл) | `Ctrl+NumPad-0` | `Ctrl+Alt+4` |
| Открыть книгу (PDF) | `Ctrl+NumPad-4` | `Ctrl+Alt+5` |
| Клиент SQL (DBeaver) | `Ctrl+NumPad-5` | `Ctrl+Alt+6` |
| Исправить раскладку | `Ctrl+NumPad-7` | `Ctrl+Alt+7` |

Исправление раскладки: выдели текст, нажми комбинацию — текст перепечатается
в другой раскладке. Работает в сессии X11; в Wayland xdotool не может
нажимать клавиши в чужих окнах, поэтому на экране входа выбирай
"Ubuntu on Xorg".

## Терминал

| Команда | Действие |
|---|---|
| `fuck` | исправить предыдущую команду |
| `ll`, `la`, `l` | списки файлов |
| `gs`, `ga`, `gc`, `gl` | git status / add / commit / log |
| `update` | обновить систему |
| `clear` или `c` | очистить экран |
